# 📱 Smart Planner

Application mobile de gestion de projets académiques développée en **React Native** avec **PHP/MySQL** et **IA**.

## ✨ Fonctionnalités

- Création et gestion de projets académiques
- Communication en temps réel (WebSocket)
- Assistant IA intégré (Groq API)
- Traitement de fichiers PDF
- Application Android (APK)

## 🛠️ Technologies utilisées

- **Frontend mobile** : React Native, Expo, React Navigation, AsyncStorage
- **Backend** : PHP 8, MySQL 8, API REST, PDO
- **Temps réel** : WebSocket (Ratchet)
- **IA** : Groq API, traitement PDF
- **Outils** : EAS Build, Git, VS Code
